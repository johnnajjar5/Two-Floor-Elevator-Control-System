# Two-Floor Elevator Control System | ARM & Embedded Systems ⚙️

## 🎯 Overview

The **Two-Floor Elevator Control System** is a microcontroller-based embedded systems project designed to control the operation of a two-floor elevator, with an emphasis on reliable operation, user convenience, and safety.

The system uses an **ARM microcontroller** as its main control unit, **ultrasonic sensors** for floor detection, and **Bluetooth communication** to support remote emergency control.

The project demonstrates the integration of embedded programming, sensor-based detection, wireless communication, and control logic in a practical electromechanical application.

## 🚀 Key Features

- **ARM-Based Control:** Microcontroller-based control of the elevator's operation.
- **Ultrasonic Floor Detection:** Uses ultrasonic sensors to detect floor position.
- **Bluetooth Communication:** Enables remote emergency control.
- **Control Algorithms:** Implements control logic for coordinated elevator operation.
- **Two-Floor Operation:** Supports elevator movement and floor detection between two levels.
- **Safety-Oriented Design:** Emphasizes reliable operation and responsive control.

## 🏗️ System Architecture

The system is built around an ARM microcontroller that coordinates sensor inputs, control decisions, and elevator operation.

### Main Components

| Component | Function |
|---|---|
| ARM Microcontroller | Main processing and control unit |
| Ultrasonic Sensors | Floor-position detection |
| Bluetooth Module | Wireless communication for emergency control |
| Elevator Mechanism | Physical movement between the two floors |

## ⚙️ System Operation

1. **Input Detection:** The system receives information from the ultrasonic sensors.
2. **Floor Detection:** Sensor readings are used to determine the elevator's floor position.
3. **Control Processing:** The ARM microcontroller processes the inputs and executes the elevator control logic.
4. **Elevator Operation:** The controller coordinates the elevator's movement between the two floors.
5. **Emergency Control:** Bluetooth communication provides a remote emergency-control interface.
